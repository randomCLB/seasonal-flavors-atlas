# 佛手瓜苗立体插画复核

2026-09-26 的浏览器截图：正面、两侧、背面、俯视，以及 390 CSS 像素宽的手机模拟卡片。截图对应 `dist/food3d/chayote.js` 首版单梢模型。

已通过本地浏览器检查：模型轻点打开详情、拖动不误触、手机默认滑动页面、主动观察后旋转、失去 WebGL 时回到本地实拍、连续打开关闭十次后无残留画布。浏览器显示约 9248 个三角面、26 次绘制调用。真实手机和不同 GPU 的流畅度尚未实测。

它是按同种植物照片与形态描述制作的立体插画；照片未提供的背面结构为近似补全。形态参考与照片授权见 `THREEJS_PLAN.md` 和 `IMAGE_REGISTER.md`。
