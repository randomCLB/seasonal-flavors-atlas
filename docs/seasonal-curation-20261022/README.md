# 时令风物：节气精选、分类与文案整理

日期：2026-10-22

基线：`ed7bdb1c2862680c37d4ded106d736e5f92529ac`。完整目录保留 354 味。机器可读的逐期名单、主推、轮换比例及人工复核见 [audit.json](audit.json)。审计使用固定日期 2026-10-22，对应 2026 秋分至 2027 白露的 24 期。

## 真实发现与修复

- 寒露原显示 31 味，各分类合计只有 27。展示层遗漏了 seafood、flower、nuts、spice、fungus；现保留原始目录分类，将 seafood 映射为水产与肉、nuts 映射为坚果种子，并补齐所有可见类别。地图、详情和搜索使用同一映射。
- 点击“蔬菜 8”原会出现 9 张卡片，因为水果主推被强行插入。主推现在独立留在顶部，列表严格遵循筛选；空分类有一键回到全部的入口。
- 名称包含“桃”的核桃花、山核桃和包含“梨”的棠梨花、刺梨可能被误合并。去重现在区分食材类别和可食部位，并对已知海鲜别名归组。
- 不同食材共用参考照片，不再被误当成同一种食材删除。仍须有合格的照片或明确标注的生成示意，才能进入首页精选。
- 先应用起季门槛与季度带鱼选择，再做筛选及相邻轮换，避免先挑出尚未起季的同类代表或在计数之后删掉新味。主推仅从真实当季池中选出；没有新味可轮换时保留真实候选，避免空白页面。
- 9 条仅有未落实商品身份的地方渔讯暂缓进入精选，原词条和来源仍留在完整目录。详见 `SeasonSelection.holds` 与审计 JSON。
- 地图在打开该视图时加载，避免首页预载隐藏地图图片；地图、星图悬浮提示和“我的尝鲜”不再输出空图片地址。
- 南湖菱卡片重复显示的月份已清理；跨月节气的多产地食材不再因当前月匹配为空而丢失产地说明。

## 同节气重复的结论

对修改前已展示的 24 期名单做规则及人工复核，未确认同一原料在同节气重复出现。旧实现的主要缺陷是过度误删和错误归类，不能把修复叙述成“删除了已发现的同屏重复”。

当前 24 期均非空、指定主推全部命中且全年不重；每个主推均与原有赏味窗口有日期交集。当前各期未确认同一原料重复，相邻节气的重复 ID 数量占本期总数最高为 50%。不同可食部位保留，例如蒲菜与草芽、核桃花与核桃仁。品类未知的渔讯不会仅凭俗名被硬合并为一个物种。
