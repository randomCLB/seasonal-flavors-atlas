# 同一风物，多地多时

一个风物词条可以对应多个真实产区。保留一个食材 ID，地图在各产区分别出现；首页、目录、抽签轮换仍按食材计数。

现有 `placeSeasons` 每项独立保存位置、月份、精度和时令来源。本次按需增加 `seasonNote`、`flavorNote` 和 `flavorSource`，分别说明产地时令与有来源支持的原料风味。未取得产区风味依据时标注待补充，不从共通菜谱风味推断地方差异。

温州盘菜示例：温州冬批偏细嫩甜糯；宁夏贺兰秋批有脆口描述。贺兰来源中的甜糯比较对象为玉环，不改写成温州和宁夏所有批次的固定排序。佛手瓜苗保持花莲、贵州普定两个季节入口，其产区风味差异尚未确认。

地图聚合弹窗以食材和产地组合保留每条入口，两个近邻产区也不会因共用食材 ID 丢失；聚合标题仍按不同食材计数。详情用“一味风物，各地各时”逐地呈现时令、风味及对应来源，原菜谱和共通风味保留。
