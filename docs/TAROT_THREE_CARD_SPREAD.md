# 塔罗签：三牌餐桌阵

## 本次改动
保留深绿与金色牌桌、十二张原创牌及其正逆位文字，改为完整的点击仪式：洗牌 → 选择一叠切牌 → 在十二张背牌中连续取三张 → 合牌揭晓一道当季菜。此刻、转机、指引三个牌位各有意义，抽取后可展开单张解释，最终保留三张牌并给出组合解读。

洗牌时提前确定十二张互不重复的牌和正逆位。切牌实际旋转牌序；选择的位置决定拿到哪一张，顺序决定牌位。不能重复拿同一张、不能取第四张，也不能在三张未齐时直接解牌。快速连点有状态锁；部分抽取后允许清空重新洗牌。

## 菜品与签文
三张牌的意象、正逆位和位置共同参与有上限的象征性加权；三牌整体决定一道菜，不各自生成三道菜。牌义、组合叙事仅为虚构娱乐，不做真实命运推断。时令、产地、菜谱、图片标记和明确忌口仍沿用原有资料与过滤；解牌当刻重检，不因玩牌跨日而使用过期候选。不读取风味签答案、不访问日历、不新增存储或传感器权限。默认没有五问，忌口仍可折叠选填。

重新开局会尽量避开最近两道菜；若只剩一道会明确说明重复，不忽略忌口。复制功能包含三张牌、各自牌位、完整签文、菜名与详情链接，自动复制失败提供选中文本。
