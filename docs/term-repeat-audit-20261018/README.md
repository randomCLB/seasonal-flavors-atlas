审计页面当前完整列表。页面与审计均按整个节气区间逐日核对：有 `peakTerms` 的条目只在明确列出的节气索引入选；其他条目按 `peakWindows` 日期窗口或 `peakMonths` 月份窗口判断；所有条目再经过 `seasonStartTerm` 门槛。重复率 = 与紧邻前一节气重合的条目数 ÷ 当前节气列表条目数，上限为 50%。本周期从 2026 秋分开始，秋分与前一个白露（2026）比较。这样跨月节气会同时检查两个自然月，不再只看节气开始时的月份。

### 2026-10-19 按逐节气补足口径展示

目标仍是每个节气分别与紧邻上一节气比较：重复率＝当前节气里上一节气也有的风物数 ÷ 当前节气总数。审计逐行给出“若保留现有名单，还需增加多少个只属于当前节气的风物，才能降至 50%”，并显示补足后的预期比例；这不是需要寻找的互不相同新品总数。例如大雪当前 16 味、10 味重复，增加 4 个大雪独有风物后为 10/20＝50%。每个新增仍须有来源支持其当季窗口；一个风物仅可在来源确实支持的节气中计入。
