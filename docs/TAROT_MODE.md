# 风物塔罗签

基线为 main `1fa4ebdcc84dffb1da88cd25f01c43caaea6618b`。保留线上风味签全部筛选、日历与保存逻辑，新功能不读取这些答案。

## 操作

打开 `tarot.html`，点击三张背牌之一，一次揭出一张牌及一道当季菜。无需五问、不申请位置或账号权限。可选忌口是唯一输入，不把“纯素”等硬限制交给随机算法。重新抽牌尽量避开最近两道菜。风味签页面只新增双模式入口与独立样式，不替换原功能。

12个牌名、正逆位、元素与原创牌义仅作叙事。算法按中国时区的当日与具体产地记录取得候选，按牌的文学元素给候选轻微加权，再随机选择；不宣称真实占卜。不会把“当天”冒充已经核查当年精确成熟日，界面说明资料精度与库存未知。

## 边界

- 当前主站数据与成菜图片直接复用；不添加无来源食材、不扩宽产季。
- 只抽已有成菜图及完整做法的菜；暂不把仅有果实切面照的鲜果包装成已拍摄的成菜。
- 保留已有配方签名校验与停用标记。配料过敏安全不是认证，实际配料、交叉接触仍需核对。
- 味道、口感、料理、猎奇等旧问题不进入新模式，避免条件逐层相交造成无菜可抽。
- 明确标示已有生成示意图，其他照片标为成菜参考，图片原来源仍见站内 credits 与 IMAGE_REGISTER。
- 牌义不会提出健康、财务、人际事实预测。正文一本正经，页脚和复制文本说明是虚构娱乐。
- 没有结果时如实说明，不放宽忌口或借用未来月份。仅一款时允许重复并说明原因。
- 只在本次浏览中维护最近几道菜，不读写 localStorage，也不上传答案。
- 原站首页、地图、食材数据、图片、风味推荐引擎、日历引擎保持原字节。
