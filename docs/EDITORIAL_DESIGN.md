# 时令风物 · 日间风物杂志，夜间餐桌占卜

本轮以 67 味目录为基线，只调整呈现，不改时令、产地、食谱、忌口或三牌合成规则。独立设计分支：`design/editorial-art-20261004`。

## 视觉规则

- 纸白 `#faf8f1` 为阅读底色，深绿 `#142f2a` 为正文与结构，深黄铜 `#806336` 为浅色页面的小字。食材保留自然色彩，不加统一暗色滤镜。
- 夜间牌桌保留深绿底、暖白正文与黄铜金。中文标题使用本机宋体／衬线字，正文使用无衬线字，不增加字体下载。
- 首页按一篇主特写、两篇侧栏、完整的短篇目录编排。顺序稳定，主角与每个当季条目都有完整入口，类别与计数保持原规则。
- 全年节气收为可展开的历书，当前节气与前后入口始终可见。
- 详情按「看清它 → 想吃的理由 → 第一次怎么做 → 买什么状态 → 来处与资料」展开。食用安全与做法相邻并常显。
- 牌面文字由页面绘制；逆位只旋转插画。手机结果同时展示三张缩略牌，单牌解释可展开，随后是成菜大图与合牌解读。
- 减少动态时保留完整洗牌、切牌、取牌与解牌路径。主要触控入口至少 44 × 44 像素。

## 牌面系列

12 张独立插画：太阳／花田、月亮／潮池与碗、星星／泉水、节制／两器倾水、愚者／轻装篮与小径、魔术师／厨房四器、隐者／林间灯、皇后／成熟果园、力量／温柔狮与根系、倒吊人／倒悬草束、命运之轮／种子到果实、世界／四季花环与餐具。

每张为独立生成的原创植物蚀刻与淡彩插画，无嵌入文字。全尺寸原稿保存于本地 `output/imagegen/`，网站使用压缩 WebP。它们是装饰性文学插画，不对应固定菜品，也不预测运势。

## 验证与发布

先检查首页、详情、牌桌、结果各自的桌面／手机八个画面，再检查全部牌面与首批图片编排。发布前执行现有测试、全年牌池审计，以及搜索、分享、地图、星图、24 节气与三牌流程的浏览器检查。发布后核对 GitHub Pages 文件内容；Sites 使用同一 GitHub 提交的图片资源并保留既有访问范围。
