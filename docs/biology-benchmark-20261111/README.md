# 五味风物生物档案查证实测

2026-11-11，用五个此前未建立生物档案的公开目录条目串行查证。选样覆盖食用植物、海产动物、地方野生菌名、命名地方品种及加工食品，没有复用前次佛手瓜苗示例作为样本。

**从准备、选样、查证、记录到统一复查，共 13 分 30 秒，折合每味 2 分 42 秒。** 其中逐味检索与记录共 11 分 03 秒，平均 2 分 12.6 秒。前置准备 50 秒、统一整理复查 97 秒单独计入。计时依据本机 UTC 时钟，完整记录见 [timing.json](timing.json)。

这是公开资料第一轮查证的用时，完成程度为「分类、对应关系、可核实结论、来源与缺口均有记录」，不等于每味均已确定全球最早人工培育地点、年代或地方品种育成史。不含网站制作、页面验收、全站回归及部署。

分类采用 Catalogue of Life Base 2026-10-14（datasetKey 316595），每味保留检索日期、物种 ID 和逐级读取的名录路径。四味落实到种，一味落实到属；均沿用现有公开食材 ID。JSON 中的 `not_found` 只表示本轮检索范围内尚未找到可支持对应结论的研究；`early_record` 仅表示检得较早记录；`species_unresolved` 表示食材尚不能落实到单一物种，均不得自动改写为确定起源。

## 主要依据

- 慈姑：[2024 年原始群体遗传研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0302313)、[宝应慈姑地理标志文件，正文第 843 页](https://www.cnipa.gov.cn/attach/0/20250826010509.pdf)。后者已取得公开原 PDF 并提取正文，索引摘要省略了品种名中的「侉」字，采用原 PDF。
- 蛎虾：[WoRMS 物种记录](https://www.marinespecies.org/aphia.php?p=taxdetails&id=107113)、[1991 年论文原始摘要](https://agris.fao.org/search/en/providers/122558/records/6471edd369d6cbfdd4a32d72)、[日本科技机构出版信息](https://jglobal.jst.go.jp/detail?JGLOBAL_ID=200902065456672996)。1999 年中国繁育记录是后续论文的参考文献线索，不能充当全球最早。
- 枞菌：[中科院研究团队的俗名、物种和培育报告](https://lssf.cas.cn/sszs/gykj/zgxnyssw/kycg/202011/t20201126_5057370.html)、[乳菇培养历史综述](https://italianmycology.unibo.it/article/view/12908)。名录中 Lactarius 另有鱼类同名属，已按界与命名法规排除。
- 余甘子：[育种团队品种论文的机构摘要](https://yunnan.agriir.cn/resources/detail/1/E93F76D6-2A8D-4806-B40A-D88AD6F0D12B.html?projectId=405d92be-2997-11e7-b5f5-3440b5b17484)、[2025 年原始研究 PDF，第 57 页记载认定编号](https://jxnyxb.xml-journal.net/cn/article/pdf/preview/10.19386/j.cnki.jxnyxb.2025.11.008.pdf)。仅写已核实的育种单位和认定事件，保留育成地点、年代缺口。
- 碾转：[河南经济报公开采访原文](https://www.hnjjbs.com/article/2026-06/178062497758909.html)、[2024 年小麦基因组论文机构公开存档](https://eprints.whiterose.ac.uk/id/eprint/216171/)、[2026 年格鲁吉亚植物考古论文机构摘要](https://weizmann.elsevierpure.com/en/publications/an-independent-center-for-the-origin-of-bread-wheat-in-the-neolit/)。Nature 全文通过作者机构的公开存档 PDF 核实；未把搜索摘要当作全文。

## 检查与实际产物

五份研究记录、五份分类路径快照及计时记录均已保存。已校验五个食材 ID 在当前 287 味公开目录内、名录 ID 与学名一致、缺失种层级未被补造、来源链接和检索日期齐全，以及计时求和与平均值。五味仍有上表列明的知识或来源缺口。

本轮只增加研究资料与实测记录，没有将五味接入页面，也没有上传公网。按逐味平均速度，287 味同等深度的串行初查约 10.6 小时；这只是一轮小样本外推，不是全目录最终核实及网站发布的工期承诺。
