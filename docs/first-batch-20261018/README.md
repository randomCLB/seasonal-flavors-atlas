- 全站共用新的详情结构：识别／食用状态图、名称、产地、时令、风味预期与两个行动入口；四段展开阅读。必要安全信息始终呈现；“看做法”展开、滚动并聚焦做法。

- 第一批12味补充区别依据、采购核对清单、获取方式、挑选和保存建议。原有完整两人份食谱保留；没有改写配料、做法、安全事项或忌口，因此无需重签。已检查86份配方和风味签名均匹配。
- 修复审计漏载11月新增内容，说明文档从67味更新为86味。固定日期的七段候选覆盖见 `coverage.json`；完整2027年采样见 `tarot-coverage-2027.json`。候选数不代表市场库存，也不等于首页逐月列表数。
- 新增3幅清楚标注的生成示意及2张开放许可普通菜心实拍。原12味中许可待确认的主要展示图撤下，原文件保留。已有节气背景画保留。
