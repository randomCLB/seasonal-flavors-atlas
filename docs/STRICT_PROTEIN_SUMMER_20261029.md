# 严格短时令非鱼蛋白候选 · 2026-10-29

当前数据核对：通过 `scripts/audit-reader-access.cjs` 的完整加载入口读取 FOODS。现有六月黄、澄海薄壳米、珠海禾虫、金蝉、西盟竹虫、三门青蟹等；以下三项无同名既有词条。青蟹的不同生理阶段仍应归入同种身份组，不能当不同物种累计。

## 1. 灌云豆丹的常规夏季鲜收批次 · 优先立秋

- 产地：江苏连云港灌云县，优先杨集镇孙跳村；不要扩成全国豆青虫。
- 身份：豆天蛾5龄幼虫，食用部分是挤出的组织，不是成蛾、蛹或任意豆田虫。
- 窗口：常规春/夏大豆放养批次推算约7–8月。该月窗是依据放养日加约30天的编辑推算，来源没有直接写成公历7–8月，须在资料说明里标明。设施反季节产品不能反证或冒充同批露地时令。
- 猎奇点：豆叶喂养的绿色幼虫，取出的食用组织熟后嫩黄、带豆香。
- 权威原文：[国家知识产权局《灌云豆丹地理标志产品保护要求》](https://www.cnipa.gov.cn/attach/0/20250826010509.pdf)，印刷页908–910：
  > 在春大豆上以6月上中旬放养为宜。在夏大豆上7月上中旬放养。
  > 幼虫生长30天左右到达5龄。
- 产地交叉核验：[连云港市政府《海外媒体聚焦灌云豆丹》2026-07-26](https://www.lyg.gov.cn/zglygzfmhwz/gcyw/content/564c94d5-e7cf-41d4-abfa-d5211a2c73c9.html)，正文明确杨集镇孙跳村为核心生产基地。
- 反季节限制：[农业农村部家庭农场案例PDF](https://hzjjs.moa.gov.cn/nchzjj/202303/P020230329599044315626.pdf)，明确灌云马亮农场已实现反季节供应。因此站内必须限定“常规夏季鲜收”，不能写“仅夏季有售”。
- 使用建议：可新增，category=protein，months=[7,8]，seasonBasis=harvest，优先立秋，不覆盖芒种（芒种大多仍在放养）。食用安全需另做常规核验，不能教读者自行抓无来源野虫。

## 2. 南沙黄油蟹 · 立秋/处暑

- 产地：广州南沙，龙穴岛青蟹养殖区。黄油蟹是雌青蟹的特殊状态，不是新蟹种。
- 窗口：公历7–8月，有直接在地农业部门原文支持。
- 猎奇点：膏油渗入足关节，需挑选达到“全油”状态的鲜活个体；不是任何母青蟹都能称黄油蟹。
- 权威原文：[广州市农业农村局《“蟹中之王”黄油蟹上市 南沙青蟹迎来“黄油蟹季”》2023-07-06](https://nyncj.gz.gov.cn/zw/zwyw/snyw/content/post_9094734.html)：
  > 从现在开始到下月，南沙青蟹迎来“黄油蟹季”。
- 产地与现代供应限制：[广州市科学技术局2024年报道](https://kjj.gz.gov.cn/xwlb/yw/content/post_9709341.html)明确龙穴已成南沙青蟹主产地，另报道企业每月黄油蟹产量约10吨。此证据说明现代养殖存在稳定供给；7–8月应表述为传统集中赏味/转油窗口，不可写全年其他月份没有货。
- 使用建议：可新增，months=[7,8]，seasonBasis=condition，与三门青蟹共享物种身份但保持产地/阶段分档。买鲜活可追溯养殖货；历史报道不证明2026年任何具体批次的全油率或库存。

## 3. 湛江奄仔蟹 · 芒种前后（保留农历窗口）

- 产地：广东湛江；进一步缩到特定乡镇的证据尚不充分，不能擅自挂到吴川/廉江某村。
- 身份：刚刚性成熟、尚未交配的仔蟹，重点为雌蟹生理阶段，不是青蟹新品种。
- 窗口：农历五月。映射到公历日期须按年份换算；可作为芒种/夏至前后候选，但不能固定写每年6月全月。
- 猎奇点：尚未交配的雌蟹，蟹膏呈半流沙质、壳薄肉嫩；不要与黄油蟹或任何小规格青蟹混用。
- 权威原文：[湛江市政府公开标准PDF，术语3.2.14“奄仔蟹”](https://www.zhanjiang.gov.cn/attachment/0/107/107927/1686737.pdf)：
  > 每年农历五月是食用奄仔蟹的好时期，常见的吃法是隔水清蒸以及盐焗。
- 同段定义清楚解释刚刚性成熟而未交配的仔蟹，并解释水蟹、奄仔蟹、膏蟹、肉蟹、黄油蟹均为青蟹。
- 使用建议：可新增，但其window应为lunar-month=5，若现有模型只能月份数组，须先补农历映射或只用于月窗口说明，不要伪造精确节气。地域比龙穴/杨集镇宽一级，严格卡“产地集中”时可列次优，等补足更窄产区证据。

## 暂不采用

- 徐州伏羊、苏州处暑老鸭：本轮要求排除仅节令吃肉习俗，两者不成立为鲜收短窗口。
- 永吉柞蚕蛹：当地春蚕主要制种；主要商品秋茧9月末–10月，无法填芒种/立秋/处暑缺口。[吉林省政府原文](https://www.jl.gov.cn/szfzt/jlssxsxnyxdh/gddt/202210/t20221006_8591339.html)。
- 睦洲黄沙蚬：江门政府称农历二月至四月肥美，为三个月，超出本轮约两个月门槛；未将其任意压为谷雨单月。
- 弶港黄泥螺：东台政府原文明示6月中旬至国庆前，超过两个月；未采用。
- 三门望潮：官方地方志原文称农历五月至八月最佳捕捉，也超门槛；未采用。
- 皮皮虾：有春季生殖/上市证据，但本轮未查到同时支持窄产区、≤两个月鲜收窗口且足够少见的组合。
