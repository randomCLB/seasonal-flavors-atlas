# 特色替代海产来源核验 · 2026-11-06

本轮只做公开、无账户的原文研究与去重，不改生产代码、不跑整站检查。原库原始名称及别名检索未见泥螺、彩虹明樱蛤、龟足、望潮、海鞘、紫石房蛤；现有“澄海薄壳米”与下述浙江海瓜子不可因俗名相同混并。以下六条分为 **2 条可集成、2 条秋季储备、2 条待补证**，不把后四条冒充已核成的春夏短季。

## 1. 可集成：岱山黄泥螺

- 建议 id：`daishan-spring-yellow-mudsnail`；显示名“黄泥螺”。产区：浙江舟山岱山沿岸滩涂。地图使用岱山区域中心即可，不指向具体养殖户。
- 身份：泥螺 **Bullacta exarata**；部分大陆水产名录使用 **Bullacta caurina**。本轮不靠名称争议另建两个档，也不把其他小螺代作泥螺。
- **季节原文已完整读取**：[岱山新闻网《民间手工技艺——黄泥螺的腌制工艺》](https://dsnews.zjol.com.cn/dsnews/system/2013/08/07/016761182.shtml)，2013-08-07，来源明确为岱山县非遗保护中心。正文在形态介绍后直接给出谷雨后开始、立夏旺盛、芒种前结束的地方采集周期。短摘录：“谷雨后始发，立夏为旺季”。
- **分类原文已读取**：[台湾农业部生物多样性研究所 TBN 泥螺记录](https://www.tbn.org.tw/taxa/bbbc6e34-746a-4159-91af-213ed1bf2444)，页面列 B. exarata 及 caurina 等历史异名，最后修改时间 2024-06-19。大陆对应参考为[农业农村部水产种质资源普查图册](https://www.moa.gov.cn/xw/bmdt/202107/P020210729522344049650.pdf)第94页的 B. caurina；该大PDF本轮仅见索引片段，不作为已读全文的主证据。
- 可集成窗口：**谷雨后至芒种前，约4月下旬—6月上旬前；立夏为精选锚点，也支持谷雨**。建议 `months:[4,5]`，若以节气控制则 `peakTerms:[7,8,9]`；不能为了芒种缺口把本源明确结束后的芒种列入峰值。
- 特色：薄脆小壳、身体不能完全缩壳的滩涂软体动物，与普通螺蛳明显不同；原文出自具体岱山地方生产技艺。
- 可写口感与吃法：鲜活泥螺清理黏液、泥沙后，做葱姜熟炒或熟制后调味；这是家常建议，不称原文传统菜。原文传统盐渍/酒渍工艺仅作文化来源，**不能照抄为家庭安全食谱**。
- 采购：确认标签是食用泥螺、岱山实际产区及采收批次，鲜货与罐装腌货分开；不购买来源不明的脱壳螺肉，不自行采挖。
- 边界：历史地方自然采集周期，不证明现代养殖与所有沿海泥螺全年供应都相同；不写“芒种后全球无泥螺”。无当年库存证明。

## 2. 可集成：乐清湾海瓜子（彩虹明樱蛤）

- 建议 id：`yueqing-meiyu-rainbow-clam`；显示名“彩虹明樱蛤（海瓜子）”。产区：浙江乐清湾；可具体提乐清水涨村、西门岛长埂、跳头滩涂，不能把整个浙江都称唯一产地。
- 身份：研究使用 **Moerella iridescens**；新分类亦见 **Iridona iridescens**。小型粉白薄壳樱蛤，**不是潮汕薄壳米所用的寻氏肌蛤**；不得沿用薄壳米照片或合并为同一个食材。
- **地方介绍原文已下载并目视读取整页**：[乐清双语地方介绍PDF](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web1828/site/attach/0/2109141756076487.pdf)，PDF第41页、印刷页79—80。右页海瓜子条目给出小型、薄脆、粉白壳形态及“肉肥，盛产于梅季”，并推荐葱油烹制。源文件为浙江政务公开存储的扫描PDF，封面编者本轮未另行核定，来源标签不要虚写成农业试验报告。
- **身份与集中产区的原始研究全文已读**：[徐衡等《浙江彩虹明樱蛤群体的形态和遗传多样性分析》](https://html.rhhz.net/shhydxxb/20151001576.htm)，上海海洋大学学报2016,25(4):508—514。作者来自乐清市水产科学研究所等；正文说明乐清湾为资源集中分布区，表1给出上述具体滩涂采样点。不能把论文5—7月采样日反推成独占最佳味期；味期依据仍为地方介绍的梅季。
- 日历换算依据：[浙江日报《浙江昨日入梅》](https://zjnews.zjol.com.cn/zjnews/202406/t20240610_26902122.shtml)，2024-06-10，已完整读取。气候中心受访者给出全省常年约6月8日入梅、7月8日出梅，并强调年际差异。它只帮助解释梅季的大致日历，不是食材肥度研究。
- 可集成窗口：**梅雨期，通常6月—7月上旬附近；每年起止随梅雨变化**。月份可用 `[6,7]`，精选锚点优先芒种 `[10]` 或夏至 `[11]`；不能精确写成每年6月8日准时上市、7月8日必定停售。
- 特色与吃法：瓜子般小的粉白薄壳贝，清爽细嫩；吐净泥沙、清洗后葱油炒至充分熟透，不能以刚开壳或秒数保证内部熟度。建议由正规商户提供清楚的商品名、产区及批次。
- 边界：形态相近的多个小贝也俗称“海瓜子”；采购和照片需锁定彩虹明樱蛤。研究指出异地引苗可能混杂，不能靠肉眼照片宣称乐清遗传品系鉴定或全国独占。
- 目视证据保存：`~/.agent-reach/captures/20261106-marine/yueqing-local-guide.pdf` 与 `yueqing-page41.png`。

## 3. 秋季储备：温岭望潮

- 显示名可用“望潮”；建议若录入，明确地域“浙江台州·温岭城南国庆塘、箬横东浦新塘”，不要合并全国所有俗称望潮的小章鱼。
- **现场报道全文已读**：[温岭日报《又到望潮最肥时》](https://paper.wlxww.com/html/2024-11/07/content_3056836.htm?div=2)，2024-11-07。原文称“短蛸”，具体记退潮下滩捕捉地点、当地收购和中秋后膏肥肉厚。
- **另一地区的节令报道全文已读**：[潮新闻《中秋到，宁波高档小海鲜望潮正肥》](https://tidenews.com.cn/video_detail.html?id=3568678)，2026-09-24。文中分大麦成熟时嫩、桂花开放时肥，未给学名。宁波窗口不能直接代替温岭采捕日历。
- 身份：温岭原文只明确中文“短蛸”，传统学名多作 **Octopus ocellatus**、现文献常见 **Amphioctopus fangsiao**，本轮未取得对本批食用样本的物种鉴定，不能将长蛸/真蛸同类图冒称短蛸。
- 可支持的窗口：**秋季、中秋后肥度较佳**，可作秋分/寒露储备；不支持拿来填谷雨、立夏或芒种。“大麦望”嫩味没有足够具体地点及起止窗，本轮不转成春夏新卡。
- 采购与熟制：问清商品种、捕捞水域和批次；清理内脏、口器、墨囊后充分做熟。报道中的“1分钟”“活吃”不照搬成安全时长或家庭操作建议。
- 不沿用报道里望潮吃光自身八脚繁殖的民间故事作为科学解释。

## 4. 秋季储备：霞浦笔架（龟足/佛手贝）

- 物种目标：**Capitulum mitella**，是有柄藤壶类甲壳动物，不是软体贝；不与欧洲鹅颈藤壶 Pollicipes pollicipes 混图。显示名“龟足（笔架）”可同时保留地方俗名。
- **地方融媒原文已完整读取**：[宁德网《霞浦十大时令菜》](https://www.ndwww.cn/xspd/xpxw/2023/0515/255908.shtml)，2023-05-15，来源霞浦融媒、霞浦新闻网。页面按季节分组，笔架确在**秋季**栏目；正文给出龟足对应、外海石礁采集、紧实及近似蟹肉的口感，附蒜煸做法。
- 产区证据：霞浦外海石礁；原文没有进一步限定到北礵岛，不能将纪录片里的采集人和本篇当成同一次现场记录。
- 当前可支持：**霞浦秋季地方时令选择**，不是已证实只有两个月的最肥期。本轮不为补少的春夏节气反向写成4—6月；若根任务按当前“特色为加分项”放宽，可按秋季展示且保留“地方时令资料”精度。
- 采购与熟制：买正规商业渠道已经依法采收的食用品，不鼓励攀礁采集；刷净表面、依商家指导处理根部并充分熟制。家庭可做姜葱煮/蒜炒，不能把原文焯1分钟当充分熟制保证。
- 图片：专人另核，须是同种整体头板、肉柄结构；“佛手贝”不能套佛手柑或普通螺图。
- 原文无学名拉丁拼写，C. mitella 仍需独立分类来源或正式商品标签交叉核对后落生产数据。

## 5. 待补证：真海鞘（海菠萝）

- 物种目标：**Halocynthia roretzi**，非玻璃海鞘或任意码头附着生物。地方供给线索为山东荣成养殖，不把日本宫城、韩国统营的物候直接移植中国。
- **原始研究全文已读**：[范林林等《黄海养殖真海鞘营养成分分析与评价》](https://www.spkx.net.cn/fileup/HTML/20152433.shtml)，食品科学2015,36(24)。材料明确来自山东荣成成山集团；研究比对7月和10月样品成分，10月部分成分较高。
- 证据边界：只有两个采样月的营养比较，**不是感官最佳味期、短产期或当年上市窗口的证明**。不能据此写“10月最佳”，也不能拿日本5—8月海鞘旬填中国芒种。
- 若未来录入：还需中国具体产区可购买食用商品与年度采收/肥满/感官窗口来源；采购需确认食用品种及商业来源，处理硬外被、内囊后熟制，不沿用日韩生食建议。
- 本轮不建议集成到节气池，先作猎奇候选档；图片已存在不构成季节事实已核验。

## 6. 待补证：天鹅蛋（紫石房蛤）

- 物种：**Saxidomus purpuratus**，分类目录亦见 S. purpurata 拼写。不是鸟蛋，不是北寄贝。
- **地方原文全文已读**：[芝罘区政府《地方特产》](https://www.zhifu.gov.cn/art/2025/2/27/art_51885_2916853.html)，2025-02-27。它证实紫石房蛤对应天鹅蛋、芝罘岛北侧水域及大个肥满的地方特征，**并没有给春季最佳窗口**。该网页搜索片段里的“春季产卵最佳”不能套给天鹅蛋，因为全文对应别的条目。
- 原始论文线索：[Bi et al., 2016, J. Ocean Univ. China, DOI:10.1007/s11802-016-2855-6 的大学公开PDF](https://scxy.ouc.edu.cn/_upload/article/files/c5/41/53e0e78c4948937259976be4f87c/28edafa0-7271-4fb7-a866-cb45b62eb1f1.pdf)。本轮仅通过原始索引读到摘要和作者信息，未完成全文；繁殖与营养研究也不能自动转译成最佳食用月份。
- 韩国江津湾研究出现6月肥满指数高峰，但地点不在烟台，不能直接用作芝罘/桑沟湾芒种峰值。
- 当前决定：产地特色可留作研究候选，但**本轮没有核成可用于立春/立夏/芒种的短最佳味窗**。需再补本地产区的肥度/当地鲜收采访。采购需锁定物种、实际产地及批次，清理内脏、充分熟制。

## 共同采购熟制依据与边界

- [国家市场监管总局《关于螺的消费提示》](https://www.samr.gov.cn/spcjs/yjjl/art/2024/art_b19dc4d262554983afc8c6668600beca.html)，2024-03-29，全文已读：正规渠道购买、清洗处理、熟制后食用，避免生食、半生及腌后直接食用。可支撑黄泥螺家常熟食建议；不照搬地方传统生腌程序。
- [吴川市政府转湛江市部门《关于安全食用贝类海产品的提醒》](https://www.gdwc.gov.cn/downpc/bmdh/jg/sc/dt/content/post_2148228.html)，2026-02-11，全文已读：来源与海域监测比“自己煮熟就行”更基础，贝毒并不一定被常规热加工消除。各条采购提示应要求产地、批次与正规渠道，不承诺烧熟能解决一切污染。
- “泥蒜/沙蒜/坭丁”暂不录：温州泥蒜可能指星虫，台州沙蒜/霞浦岐乳可能指海葵；不同地方名称与物种、味期不能互相挪用。本轮没有取得足以精确落到少风物节气的对应链。
- 未跑整站检查。季节池分配、去重、图片身份、计数与上线由主任务统一处理。
